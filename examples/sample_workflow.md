## مثال 1: ترجمة محاضرة من الإنجليزية إلى العربية

```bash
python main.py \
  --url "https://www.youtube.com/watch?v=YOURE_URL" \
  --lang ar \
  --provider gemini
```

**المخرجات:**
- `output/<name>.srt` — ملف الترجمة المزامنة
- `output/<name>.txt` — النص المترجم الكامل
- ملخص تنفيذي في الطرفية
- سجل محفوظ في Supabase

## مثال 2: تفريغ اجتماع محلي

```bash
python main.py --file meeting_2026_01_15.mp3 --lang en --no-summary
```

## مثال 3: استخدام Groq للسرعة

```bash
python main.py --url "..." --lang tr --provider groq
```

Groq أسرع بكثير من Gemini ولكنه يحتاج مفاتيح Groq API.
