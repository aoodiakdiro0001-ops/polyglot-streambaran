## 🚀 طريقة النشر على Hugging Face Spaces

1. أنشئ حساباً مجانياً على [huggingface.co](https://huggingface.co)
2. اضغط **New Space** واختر **Streamlit** كـ SDK
3. ارفع محتوى هذا المجلد
4. في **Settings > Repository secrets** أضف:
   - `GEMINI_API_KEY`
   - `HF_TOKEN`
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `TELEGRAM_BOT_TOKEN` (اختياري)
5. سيتم تشغيل الواجهة تلقائياً على `https://<username>-polyglot-streambaran.hf.space`
